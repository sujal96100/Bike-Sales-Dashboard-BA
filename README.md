# Bike Sales Analytics Dashboard

An interactive **Bike Sales Analytics Dashboard** built using Microsoft Excel to analyse customer demographics, income, commute distance and bike purchasing behaviour.

## Project Overview

This project analyses a dataset of **1,000 customer records** to identify patterns associated with bike purchasing decisions.

The dashboard allows users to interactively explore the data using slicers and visualisations.

## Key Features

- Interactive Excel dashboard
- PivotTables and PivotCharts
- Interactive slicers for filtering
- Customer analysis by age bracket
- Average income comparison by bike purchase decision
- Commute distance analysis
- Regional and demographic filtering
- KPI metrics for high-level performance overview

## Analysis

The dashboard examines bike purchasing behaviour across:

- Age brackets
- Average income
- Commute distance
- Education
- Marital status
- Car ownership
- Region

## Tools & Technologies

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Excel formulas
- Data analysis and visualisation

## Dataset

The project uses a dataset containing **1,000 customer records** with demographic, financial and commuting attributes.
